# ヨット部 配車ツール

部活の移動で、全員が乗れるかをすぐ確認するためのツールです。

**公開ページ:** https://kennyyossy.github.io/driver-tool/

## できること

- 全体の人数を入力
- 車を好きな台数だけ追加・削除し、それぞれの乗れる人数を ＋− で調整
- 車以外の移動手段（原付・バス・自転車）の人数も ＋− で調整
- 全体の人数から合計を引いた過不足を、画面下に常時表示
  - `−6` … あと 6 人分たりない
  - `±0` … ぴったり全員乗れる
  - `+1` … 1 人分の余裕がある

入力内容はブラウザに自動保存されるので、ページを閉じても残ります。

## 構成

`index.html` の 1 ファイルのみ。外部ライブラリを使っていないので、ファイルを直接ブラウザで開いても動きます。
